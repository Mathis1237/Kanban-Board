# Kanban (Android, offline)

Offline-Kanban-Board als Android-App. Alle Daten bleiben lokal auf dem Handy.

## APK bekommen
Bei jedem Push baut GitHub Actions die APK automatisch. Danach unter
**Releases → "Kanban (neueste Version)" → Kanban.apk** herunterladen und installieren.

## Bedienung
- Karte antippen: bearbeiten (Titel, Notizen, Fälligkeit, Farbe, Spalte)
- Karte lange drücken und ziehen: verschieben (auch zwischen Spalten, am Rand scrollt es)
- Spalten wischen: seitlich
- Drei Punkte an einer Spalte: umbenennen, verschieben, löschen
- Menü oben rechts: Backup exportieren (landet in Downloads) / importieren
